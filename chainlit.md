
# Bienvenue sur Puls-Events ! <br>

**Votre assistant intelligent de recommandation d'événements culturels en France.** <br>

---

### Comment ça marche ? <br>
```
1. **Choisissez votre ville** via les paramètres ⚙️ à droite
2. **Posez votre question** librement :
   - *"Quels concerts ce week-end ?"*
   - *"Événements gratuits en juin à Lyon ?"*
   - *"Expositions d'art contemporain ?"*
3. **L'assistant cherche** dans la base locale puis sur le web si besoin
```
---

### Technologie <br>
```
| Composant | Technologie |
|---|---|
| Base vectorielle | Qdrant Cloud |
| LLM | Mistral-7B |
| Agent web | smolagents (Hugging Face) |
| Mémoire | Conversationnelle (10 tours) |
```
